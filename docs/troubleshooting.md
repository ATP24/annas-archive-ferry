# 排障 / Troubleshooting

## 安装后找不到 `annas-ferry`

确认已激活创建的虚拟环境，并在同一环境执行 `python -m pip install -e .`。也可在仓库目录直接运行 `python scripts/ferry_engine.py --help`。

## 找不到浏览器

先运行 `annas-ferry doctor`。系统 Chrome 或 Edge 可供 Playwright 使用；也可以执行 `python -m playwright install chromium`。CI 只验证离线行为，不保证当前机器能访问站点。

## `search` 无结果或访问失败

先区分两种情况：空数组 `[]` 表示页面解析没有找到结果；非零退出码表示检索失败。尝试更短的书名、检查站点和代理。网站页面或防护变化可能需要更新解析器；请附脱敏后的错误信息提交 Issue。

## `probe` 返回未知大小或失败

下载服务器可能不提供 `Content-Length`，或者慢速通道和验证码未能通过。探测不会为测速而读取文件内容，也不会给出假定速率的耗时预测。直链可能过期；稍后重新探测。

## 下载留下 `.part`

网络中断时保留部分数据以便重试。同一资源再次下载时才尝试续传；若服务器忽略范围请求，会重新下载。校验失败的文件不会被报告为成品。不要手工把 `.part` 改成正式扩展名。

## `--json` 解析失败

只解析标准输出，不要把标准错误输出与它合并。`search` 和 `probe` 的标准输出应为单个 JSON 值。如果出现日志混入，请附命令和脱敏后的输出报告问题。

## 报告问题前

提供操作系统、Python 版本、命令、退出码、相关错误、是否使用代理，以及复现步骤。**不要**贴出完整的临时下载直链、凭据或本地私人路径。参见 [安全说明](../SECURITY.md)。
