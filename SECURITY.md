# Security Policy / 安全说明

Please report security issues privately through GitHub's **Report a vulnerability** feature if available. If private reporting is unavailable, open a brief Issue requesting a private contact channel without publishing exploit steps, credentials, signed URLs, or personal files.

请优先使用 GitHub 的私密漏洞报告功能。若不可用，请先发不含利用细节的 Issue 联系维护者；不要公开临时直链、凭据或私人文件。

This project handles untrusted site content and downloads. Only use trusted mirrors and proxies. The CLI checks HTTPS and public addresses for direct downloads, but users remain responsible for downloaded content and local execution permissions.
